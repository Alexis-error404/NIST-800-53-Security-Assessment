# Evidence Collection Guide

| ID | Control | Artifact | Demonstrates |
|---|---|---|---|
| EV-001 | AC-2 | AD account inventory | Account lifecycle/status |
| EV-002 | AC-6 | Privileged groups | Least privilege |
| EV-003 | IA-5 | Password policy GPO | Authentication settings |
| EV-004 | IA-5 | Lockout GPO | Lockout configuration |
| EV-005 | AU-2 | Audit Policy | Event configuration |
| EV-006 | AU-2/AU-6 | Security Event Log | Logged events |
| EV-007 | CM-6 | Security GPO | Standardized settings |
| EV-008 | SI-2 | Update status | Patch evidence |

## Evidence Quality
I would validate relevance, currency, system scope, completeness, source authenticity, and whether evidence demonstrates design only or actual operating effectiveness.

**Naming example:** `EV-002_AC-6_Privileged-Groups.png`

Never publish real credentials, tokens, PII, sensitive IPs, or production information.
